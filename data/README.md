# 데이터 파일 작성 가이드

이 폴더의 JSON 파일을 수정하면 홈페이지 화면에 자동으로 반영됩니다.
코드를 건드릴 필요 없이, 아래 형식에 맞춰 항목을 추가/수정/삭제하면 됩니다.

JSON 파일에는 주석을 쓸 수 없기 때문에, 각 파일의 작성 규칙을 이 문서에 정리했습니다.

## members.json (구성원)

| 필드 | 필수 | 설명 |
|---|---|---|
| `id` | 필수 | 영문·숫자·하이픈으로 만든 고유 값 (다른 항목과 겹치면 안 됨) |
| `name` | 필수 | 이름 |
| `role` | 필수 | `교수`, `연구교수`, `박사과정`, `석박통합과정`, `석사과정`, `학부연구생` 중 하나만 사용 |
| `email` | 선택 | 이메일 주소. 없으면 `""` |
| `photo` | 선택 | 증명사진 경로(예: `img/members/hong-gildong.jpg`). `img/members/` 폴더에 파일을 넣고 그 경로를 적으면 됨. 정사각형에 가까운 사진을 권장(자동으로 정사각형으로 잘려서 표시됨). 없으면 `""`이거나 필드 자체를 생략 |
| `interests` | 선택 | 관심 분야 목록. 없으면 `[]` |
| `bio` | 선택 | 한 줄 소개. 없으면 `""` |

## publications.json (논문/실적)

| 필드 | 필수 | 설명 |
|---|---|---|
| `id` | 필수 | 영문·숫자·하이픈으로 만든 고유 값 |
| `title` | 필수 | 논문 제목 |
| `authors` | 필수 | 저자 목록 |
| `venue` | 필수 | 학회 또는 저널명 |
| `year` | 필수 | 발표 연도 (4자리 숫자) |
| `type` | 필수 | `저널`, `학회` 중 하나만 사용 |
| `link` | 선택 | 논문 링크. 없으면 `""` |
| `summary` | 선택 | 요약. 없으면 `""` |
| `citedBy` | 선택 | 피인용 횟수(정수). 0이면 배지가 표시되지 않고, 1 이상이면 "피인용 N회" 배지로 표시됨. 없으면 `0` |

## news.json (공지사항)

| 필드 | 필수 | 설명 |
|---|---|---|
| `id` | 필수 | 영문·숫자·하이픈으로 만든 고유 값 |
| `title` | 필수 | 제목 |
| `content` | 필수 | 내용 |
| `author` | 필수 | 작성자 |
| `publishedAt` | 필수 | 게시 일시 (`YYYY-MM-DDTHH:mm:ss+09:00` 형식). 목록 정렬 기준으로 쓰임 |
| `updatedAt` | 선택 | 수정 일시. 값이 있으면 "수정됨" 표시만 되고 정렬에는 영향 없음. 없으면 `""` |
| `link` | 선택 | 관련 링크. 없으면 `""` |
| `pinned` | 선택 | `true`면 날짜와 무관하게 목록 맨 위에 고정 배너로 표시. 없으면 고정 안 됨 |
| `category` | 선택 | 목록에 작은 뱃지로 표시되는 분류(예: `모집`, `합류`, `논문`, `세미나`). 자유 텍스트이며 없으면 뱃지가 표시되지 않음 |

## 공통 주의사항

- 각 파일은 전체가 하나의 배열(`[ ]`)이어야 합니다. 항목을 추가할 때는 배열 안에 `{ }` 블록을 콤마로 구분해 추가하세요.
- 마지막 항목 뒤에는 콤마를 붙이지 않습니다.
- 값을 수정한 뒤에는 JSON 형식이 깨지지 않았는지(따옴표, 콤마, 괄호) 확인하세요.
